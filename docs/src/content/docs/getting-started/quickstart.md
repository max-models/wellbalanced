First, ensure that `wellbalanced` is [installed](/wellbalanced/getting-started/installation/).

## Basic usage

After installation, you can run the application with:

```bash
wellbalanced
```

which calls `wellbalanced.main.main` and prints a greeting.

## Use the package from Python

```python
from wellbalanced.main import main

main()
```

See the [API reference](/wellbalanced/api/wellbalanced/) for every module and function.
